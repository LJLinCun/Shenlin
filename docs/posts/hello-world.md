# Hello World

想了很久什么时候开博客，一直拖着没动手。今天终于把架子搭起来了——与其等一个完美的时机，不如先从不完美的东西开始。

我平时主要做两件事：前端开发（特别是 Next.js + React）和游戏开发（UE5 蓝图）。这个博客会围绕这些主题展开，偶尔也写点其他想说的话。

## 为什么写博客？

- **记录** — 很多技术思考只在一瞬间清晰，写完才算真正理解
- **分享** — 如果我的踩坑经验能帮到别人少走弯路，那就值了
- **输出倒逼输入** — 为了写出好文章，必须认真读、认真想

## 博客里会写什么？

1. **技术笔记** — Next.js、React、游戏引擎相关的实战心得
2. **教程类** — 从零开始的完整指南（比如这个博客是怎么搭建的）
3. **项目记录** — 做东西的过程，踩了哪些坑，学到了什么
4. **偶尔的随笔** — 和代码无关的思考

## 写在最后

博客名字就叫"林寸"好了——简单直接。标题用了中文模板：每篇文章显示为 "文章名 · 林寸"，看起来比英文舒服。
